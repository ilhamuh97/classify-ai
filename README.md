# Classify AI

This project is built with [Vite](https://vitejs.dev/), React 19, and TypeScript.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in development mode with hot module reloading.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`

Runs the test suite once with [Vitest](https://vitest.dev/).\
Use `npm run test:watch` to run it in interactive watch mode instead.

### `npm run build`

Type-checks the project and builds it for production to the `build` folder.\
The build is minified and the filenames include content hashes, ready to be deployed.

### `npm run preview`

Serves the production build locally so you can sanity-check it before deploying.

### `npm run lint`

Lints all TypeScript source files. Use `npm run lint:fix` to auto-fix what it can.
